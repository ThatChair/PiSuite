- SDK: `docs/sdk.md`; custom providers: `docs/custom-provider.md`; models: `docs/models.md`
- Packages: `docs/packages.md`; environment variables: `docs/environment-variables.md`
- MCP servers (when supported by this Pi version): `docs/mcp.md`
